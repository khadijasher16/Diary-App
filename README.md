# 💖 Smart Diary Web App

## 📌 Overview  
Smart Diary is a feature-rich journaling web application that allows users to write, manage, and organize daily entries in a clean and user-friendly interface. The app simulates a personalized diary system with persistent storage and interactive features.

## ✨ Features  
- 🔐 User-based login system (local storage)  
- 📝 Add, edit, and delete entries (CRUD operations)  
- 🔍 Search functionality  
- 📂 Categorize entries (Personal, Study, Goals)  
- 💾 Data saved using localStorage  
- 🌙 Dark mode toggle  
- 📅 Date and time tracking  
- 💅 Clean and responsive UI  

## 🛠️ Technologies Used  
- HTML  
- CSS  
- JavaScript  
- Google Fonts  
- LocalStorage  

## 🎯 Purpose  
This project was built to practice front-end development and simulate real-world application behavior using JavaScript. It demonstrates DOM manipulation, user interaction, and persistent data handling.

## 🚀 How to Run  
1. Download or clone the repository  
2. Open the folder  
3. Open `index.html` in your browser
